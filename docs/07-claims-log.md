# Your Own Claims Log

*Admin help only — bookkeeping tips, never medical, legal, or financial
advice.*

## Why a log (the honest version)

The real problem with medical paperwork isn't ability — it's that it arrives
scattered over months, in different envelopes, and lives only in your memory
between them. A claims log fixes that with one row per claim. It takes about
a minute to update, and every future chapter of this guide gets easier
because of it: disputes cite it, assistance applications reference it, payment
plans sit inside it, and insurers can't out-wait you.

## The nine columns

Use the printed [claims log worksheet](worksheets/claims-log-worksheet.md),
or any spreadsheet — these columns:

| Column | What goes here |
| --- | --- |
| **Date opened** | When the claim/bill first arrived |
| **Who** | Provider (and insurer if different) |
| **DOS** | Date of service |
| **Claim / acct #** | The number both sides use |
| **Billed** | Sticker price (optional, but useful context) |
| **Allowed** | The real contracted price, per EOB |
| **My share** | Your responsibility per EOB |
| **Status** | Paid / Pended / Disputed / Plan / Assistance / Closed |
| **Last action + date** | What happened last and when — this is the memory |

The **"last action"** column is the secret weapon. One line like
"Disputed 4/2 by mail, tracking #1234, follow-up due 5/2" is the difference
between "I think I sent something" and a system.

## Five habits, one minute each

1. **One row per claim**, created the day the first paper arrives.
2. **Update only the last-action cell** — nothing else needs maintenance.
3. **Keep the paper** (or a scan/photo) of bill, EOB, and letters in a folder,
   paper or digital, named by date+provider.
4. **Weekly 5-minute glance:** any row where last-action is more than
   30 days old and status isn't Closed? That's your one follow-up this week.
5. **Close rows** with a one-word note: "Paid," "Zero balance," "Plan ended."
   Closed rows are the calm part of the log.

## Folders and backups, minimal edition

- Name files like `2026-03-12_maple-clinic_bill.pdf` — date first so folders
  self-sort.
- Everything local-first: keep copies on your own computer or a thumb drive;
  this guide has no cloud requirement.
- If you like the printed page, the
  [printable worksheet](worksheets/claims-log-worksheet.md) lives happily in a
  binder with the actual bills.

> Privacy note: keep your log for yourself; you never send the log to anyone
> voluntarily. Its job is to make *you* the organized party, not to become
> another disclosure.

## What "ahead" feels like

The log converts a pile of envelopes into ten quiet rows. Each row either
needs one small action or is closed. That is the entire emotional promise of
this manual: paperwork becomes a list, not a feeling.
