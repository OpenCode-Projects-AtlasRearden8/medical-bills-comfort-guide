# Call Notes Worksheet (printable)

One sheet per call. Keep call notes with the matching claim in your log
([Chapter 7](../07-claims-log.md)); the handy part is writing the *next step*
before you hang up.

```
Who I called:        ____________________________   Number: ______________
Date / time:         ____________________   Spoke with: __________________
Reference name / ID: _________________________________________
Re (account/claim):  ____________________________   DOS: ______________

What I asked:
1. ___________________________________________________________
2. ___________________________________________________________
(keep it to one or two asks — calls go better short)

What they said:
- ___________________________________________________________
- ___________________________________________________________

Confirmed in writing?  [ ] yes (portal / mail)  [ ] asked  [ ] not yet
Account noted as of today?  [ ] yes  [ ] unsure

Actually paid / promised amount if any: $__________

NEXT STEP:             ______________________________________________
Due by (date):         ______________   Set reminder?  [ ] done
```

**Ends-of-call lines that save headaches:**
- "Could I get your name so I can mention it if I need to call back?"
- "Could you note on the account that I called today about this?"
- "And the next step is ___? Great — thank you for your patience with me."
